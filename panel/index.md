# Korzystanie z panelu

Panel jest dostępny pod adresem [panel.spaceis.pl](https://panel.spaceis.pl). Po zalogowaniu wybierz licencję sklepu, którym chcesz zarządzać.

## Wybór sklepu

Krok 1. Otwórz **Moje licencje**.

Krok 2. Przy wybranym sklepie kliknij **Otwórz panel**. Bieżący sklep jest widoczny w górnej części menu.

Krok 3. Aby zmienić sklep, użyj wyboru licencji w menu lub wróć do listy licencji.

!!!
Serwery, produkty, transakcje i statystyki dotyczą wybranej licencji. Przed zmianą ustawień sprawdź nazwę sklepu w menu.
!!!

## Najważniejsze miejsca

| Miejsce | Do czego służy |
| --- | --- |
| Kokpit | Podsumowanie sprzedaży i ostatnie transakcje. |
| Statystyki | Przegląd sprzedaży oraz zestawienia produktów, metod płatności i klientów. |
| Transakcje | Statusy zakupów, pozycje koszyka i eksport CSV. |
| Sklep | Serwery, kategorie, produkty, warianty i podstrony. |
| Strona płatności | Wygląd koszyka, własna domena oraz linki do dokumentów sklepu. |
| Płatności | Konfiguracja bram i informacje o błędach płatności. |
| Webhooki | Powiadomienia o zakupach na Discordzie. |
| Ustawienia konta | Dane konta i połączenia z Google lub Discordem. |
| Weryfikacja dwuetapowa | Dodatkowe zabezpieczenie logowania. |
| Dziennik zmian | Historia działań w wybranej licencji, jeśli masz do niej uprawnienia. |

Znacznik **BETA** oznacza funkcję rozwijaną w ramach nowej strony płatności. Jej dostępność może zależeć od ustawień usługi.
